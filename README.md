Undead Bullets

Description:
You are Frankenstein's monster. You got trapped in a dungeon with only one way out... by surviving the relentless bullets from the monster trapped with you.

How to Play:
You have 1 minute and 30 seconds that you need to dodge and weave the monster's bullets. Use use WASD or arrow keys to move.
